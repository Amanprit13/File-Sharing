# 📁 File Dropper – Secure File Sharing Platform

File Dropper is a secure and efficient file sharing system that allows users to upload files and generate shareable links with controlled access.

---

## 🚀 Features

- 🔐 Password-protected file access  
- ⏳ Expiry time for links  
- 📥 Download limit control  
- 📂 Drag and drop file upload  
- 🔗 Instant shareable link generation  
- 🗂️ File management (view, download, delete)  

---

## 🛠️ Technology Stack

- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Flask (Python)  
- **API:** REST APIs  
- **Storage:** Local File System  
- **Database:** JSON (for metadata)

---

## ⚙️ How It Works

1. User uploads a file  
2. Sets options (password, expiry, download limit)  
3. File is stored on server  
4. Unique shareable link is generated  
5. Receiver accesses file using the link  

---

## 🔐 Security Features

- Password protection  
- Expiry-based access  
- Download limit restriction  
- Backend validation  
- Prevention of unauthorized access  

---

## ⚠️ Limitations

- No user authentication system  
- Uses local storage instead of database  
- Limited scalability  

---

## 🔮 Future Scope

- Cloud storage integration (AWS, Google Drive)  
- User login and authentication  
- File encryption  
- Mobile app support  
- Real-time sharing  

---

## 📌 Conclusion

File Dropper provides a simple, secure, and user-friendly way to share files with controlled access. It can be further enhanced with advanced security and scalability features.
